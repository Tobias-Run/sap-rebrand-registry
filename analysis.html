    What the index is not

    It is not a probability, and nothing in it comes from SAP. It combines two things the register can see — how often a product has been renamed per year of its recorded history, and how far its current name has run against the length its names usually reach. A product that has never been renamed scores low because nothing has happened to it, not because something has been ruled out.

    What these figures cannot see

    Names that have not ended yet
    A running name has no length, only a length so far. It is left out of the median rather than counted as short, which is why the median is a floor: names still in force can only turn out longer than the ones already replaced.
    Dates that are later than the truth
    Most start dates in the register are "in use by" — the earliest point a name can be proven, usually an annual report. A name adopted in April first appears the following February. Every period built that way is measured shorter than it really was, so the medians here run low.
    Whether a current name is still current
    A running name has no end date because no source says it ended, which is not the same as a source saying it is still in use. Each one now records when it was last seen in a filing, and the section above shows how far back that is.
    Products that are not in the register
    A product is listed once its chain of names can be sourced. Discontinued products are out of scope entirely, which removes exactly the cases where a name ended for reasons that had nothing to do with branding.
    Small numbers
    A family with one or two renames behind it gets a median that is really just one number wearing a statistic's clothes. Those rows are marked rather than hidden.
